 VULNERABILITY #3: Client-Side Content Access Control 
 Severity: HIGH 
 CVSS: 8.1 


LOCATION: 
 - com/appnew/android/player/YoutubePlayerActivity.java
 - Lines: 2213, 2219, 2253, 2259

CODE:
 if (this.islocked.equalsIgnoreCase("1")) {
 // Show locked UI, prevent playback
 } else if (this.islocked.equalsIgnoreCase("0")) {
 // Allow playback
 }

ISSUE:
 - "islocked" parameter passed via Intent extras
 - Checked client-side ONLY before playback
 - No server-side validation
 - Can be modified at runtime

EXPLOITATION:
 - Runtime hooking (Frida) sets islocked="0"
 - APK patching removes check entirely
 - Intent manipulation bypasses lock

IMPACT:
 - Paid content accessible without payment
 - Course 48297 (and all paid courses) vulnerable
 - Direct revenue impact
