TROUBLESHOOTING
================================================================================

ERROR: "run-as: Package 'com.eduteria.app.app' is not debuggable"
SOLUTION: The app is not debuggable. You need either:
 1. Root access (run `adb root` first)
 2. Modified APK that's debuggable
 3. Use Method 4 below (backup/restore)

ERROR: "sqlite3: not found"
SOLUTION: The phone doesn't have sqlite3 installed.
 Try installing via: adb push <sqlite3-binary> /data/local/tmp/
 Or use Method 4.

ERROR: "Permission denied"
SOLUTION: Need root access. Try `adb root` or root your phone.

METHOD 4: BACKUP/RESTORE HACK (NO ROOT NEEDED!)
================================================================================

This works even on non-rooted phones!

STEP 1: Backup app data
 $ ~/platform-tools/adb backup -f eduteria_backup.ab com.eduteria.app.app
 
 On your phone: Approve the backup (may ask for password - leave blank)

STEP 2: Convert backup to tar
 $ dd if=eduteria_backup.ab bs=24 skip=1 | openssl zlib -d > eduteria.tar

STEP 3: Extract the tar
 $ tar -xvf eduteria.tar

STEP 4: Find and modify the database
 $ cd apps/com.eduteria.app.app/db/
 $ sqlite3 utkash.db
 
 sqlite> INSERT INTO MycourseTable (id, title, userid, purchase_date, is_activated) VALUES ('48297', 'BPSC Course', '54204924', datetime('now'), '1');
 sqlite> .quit

STEP 5: Repack the tar
 $ cd ../../..
 $ tar -cvf eduteria_modified.tar apps/

STEP 6: Convert back to Android backup format
 $ dd if=/dev/zero bs=24 count=1 > eduteria_modified.ab
 $ openssl zlib -in eduteria_modified.tar >> eduteria_modified.ab

STEP 7: Restore modified backup
 $ ~/platform-tools/adb restore eduteria_modified.ab
 
 On phone: Approve restore

STEP 8: Test
 - Open EDUTERIA
 - Go to "My Courses"
 - Should see course 48297!
